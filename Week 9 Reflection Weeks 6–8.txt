## Part 3: Code Does Not Live Alone

Code is connected to more than just writing instructions for a computer. Developers need hard skills, such as programming, testing, and using development tools, but they also need soft skills like communication, organization, and problem-solving.

During this project, I used tools like Visual Studio and GitHub to create, test, and organize my work. Documentation and assignment instructions helped me understand what needed to be completed and how to structure my project. Examples and tutorials helped me learn new concepts and make decisions while developing.

Even when working independently, developers rely on information from other people through instructions, examples, and feedback. Being able to explain problems clearly and document decisions helps make projects easier to understand and improve.

## Part 4: What I Would Change

If I could redo Weeks 6–8, I would organize my files earlier and document my changes as I worked instead of waiting until the end. I would also test each feature sooner after adding it so problems would be easier to identify and fix. I would spend more time reviewing my project structure before submitting to make sure everything was easy to find.
